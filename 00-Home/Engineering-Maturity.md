# 📈 Engineering Maturity

Track progression from developer to architect-level thinking.

```text
Java Developer
      ↓
Java Backend Developer
      ↓
Spring Boot Developer
      ↓
Enterprise Backend Engineer
      ↓
Senior Backend Engineer
      ↓
Backend / System Design Engineer
```

## Signals by level

### Junior
- Writes correct code with guidance
- Knows core Java syntax and collections

### Mid-level
- Understands Spring internals, not just annotations
- Writes tests, reasons about transactions and concurrency

### Senior
- Designs services and data models
- Reasons about failure, consistency, and trade-offs
- Debugs production incidents

### Staff / Architect
- Designs systems across services
- Makes and documents architecture decisions ([[Architecture-Decision|ADRs]])
- Balances business and engineering constraints
